Set up the form's token

Encrypts the GitHub token with your passphrase, here in this browser. Nothing you type leaves this page. Do this on your own computer.

  1. Paste the fine-grained token that can only run workflows in ihe-transcribe.
  2. Choose a long passphrase: five or six random words is good. Anyone who has it can start runs.
  3. Press Encrypt, download token.enc.json, and replace the file of that name in the repo.
